# Flow Launcher プラグイン要件定義書：App Manager

## 1. 導入
### 1.1 目的
本ドキュメントは、Flow Launcher 用プラグイン「App Manager」の開発における機能および非機能要件を定義するものである。

### 1.2 背景
Flow Launcher において、インストールされているアプリの全体像（Windowsの標準的なアプリ一覧）を把握し、特定のアプリへ最短でアクセスする手段を提供する。利用履歴やカスタム設定に基づき、ユーザーの思考を妨げない検索・起動体験を実現する。

### 1.3 ターゲットユーザー
* キーボード操作を主体とし、特定のアプリを独自のキーワード（エイリアス）で即座に呼び出したい Windows ユーザー。

## 2. 全体概要
### 2.1 製品コンセプト
「最短・最速のアプリケーション・ランチャー拡張」

### 2.2 主要機能一覧
* アクションキーワード `ap` による専用検索モード。
* 利用履歴（最終使用日時）に基づく動的な表示順位の最適化。
* ユーザー定義のキーワード（エイリアス）による直接アクセス。
* Flow Launcher 設定画面を通じた GUI カスタマイズ。

## 3. 機能要件
### 3.1 検索機能（何を表示し、どう探すか）
* **3.1.1 起動条件**: `ap `（末尾スペース）の入力を検知してプラグインが動作を開始すること。
* **3.1.2 検索対象（OS管理リスト基準）**:
  * **Windows標準のアプリ一覧**: Shell API（`shell:AppsFolder` 相当）やレジストリから取得できる、システムにインストール済みのアプリケーション。
  * **カスタムパス**: ユーザーが設定画面で個別に追加した特定のディレクトリ、または実行ファイル。
  * **重複の扱い**: カスタムパス等で同一の実行ファイルが複数ルートで登録された場合、それぞれを独立したエントリとして表示・選択可能にすること。
* **3.1.3 検索ロジック**: 
  * **Flow Launcher 標準ロジックの利用**: 自前での検索実装は行わず、Flow Launcher 本体が提供する検索アルゴリズム（Fuzzy Search / スコアリング）を利用してマッチングを行う。
* **3.1.4 日本語・特殊文字対応**: アプリ名に含まれる日本語（全角文字）や記号を正しく認識・検索できること。
* **3.1.5 キャッシュ更新**: 
  * アプリ一覧の取得はプラグイン起動時にバックグラウンドで実行し、動作中はキャッシュを利用して高速化すること。
  * スキャン完了までは前回終了時のキャッシュデータを暫定使用する。
  * **初回起動時（キャッシュ未作成時）**: スキャンが完了した項目から順次、シンプルに一覧表示を行うこと。

### 3.2 ランキング・ソート機能（どの順で出すか）
* **3.2.1 履歴優先表示**: クエリ未入力時、最後に使用した日時が新しい順に表示すること。
* **3.2.2 ピン留め**: ユーザーが明示的に指定したアプリを、検索結果の最上位に固定すること。
* **3.2.3 エイリアス優先**: ユーザー設定の「別名」との一致を最優先スコアとする。

### 3.3 実行機能（どう起動するか、した後に何をするか）
* **3.3.1 実行の委譲と識別**: 
  * 選択されたアプリを Flow Launcher 本体の実行機能（ShellRun）に渡す。
  * 識別子として、Win32アプリは「OSから提供される起動用パス（.exeまたは.lnk）」、UWPアプリは「AppUserModelId (AUMID)」を使用する。
* **3.3.2 履歴の更新**: アプリが正常に起動された際、内部データの「最終使用日時」を更新・保存すること。
* **3.3.3 標準操作の継承**: 右クリックメニューやショートカットキー（管理者実行等）は Flow Launcher 本体の仕様に従うこと。

### 3.4 管理・設定機能（ユーザーがどう変えるか）
* **3.4.1 GUIカスタマイズ**: エイリアス、ブラックリスト、カスタムパス等を編集できること。
* **3.4.2 設定のバックアップ**: 設定データを JSON 形式でエクスポート・インポートできること。

### 3.5 表示要件（UI）
* **3.5.1 レイアウト**: 
  * タイトル：アプリケーション名（またはエイリアス名）を表示。
  * サブタイトル：アプリケーションのフルパスを表示。
  * アイコン：各アプリケーションに関連付けられた標準アイコンを表示。

## 4. 非機能要件
### 4.1 パフォーマンス
* **4.1.1 応答速度**: 入力から結果表示まで 100ms 以内を維持すること。
* **4.1.2 効率的な取得**: 不要なディスクスキャンを排除すること。

### 4.2 信頼性・保守性
* **4.2.1 データの永続化**: PC 再起動後も設定と履歴が保持されていること。
* **4.2.2 データクレンジング**: 
  * 実体が存在しなくなったアプリの履歴は原則削除する。
  * ただし、カスタムパス等で指定された外部ドライブのアプリに配慮し、一定期間（例：30日間）再検出されない場合のみ自動削除する猶予を設けること。
* **4.2.3 アップデート対応**: 設定項目追加時の自動デフォルト値補完機能を備えること。

## 5. 制約事項
* Windows 10/11 環境。
* Flow Launcher プラグイン API 仕様に準拠。
